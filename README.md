## About

This project started as a bit of a mess, but I refactored it to make it cleaner, easier to navigate, and more maintainable. The goal was to make it simple for others to explore the code, learn, or even use parts of it for their own projects.

---

## Usage

Feel free to:

- Explore the code
- Learn from the structure, animations, and components
- Reuse any parts for your own projects

No permission required, just give credit if you use it publicly.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Animations:** CSS transitions and keyframes / setTimeout and rAF
- **Frameworks/Libraries:** Vanilla JS / Vite & handlebars from "vite-plugin-handlebars"
